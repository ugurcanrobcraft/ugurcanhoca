👋 Selam! Modelini seçip API anahtarını girdikten sonra yukarıdan bir dil veya Jubbio Bot seçip öğrenmeye başlayabilirsin! Kod bloklarındaki 📄 kopyala butonunu kullanabilirsin.

📖 API Key & Sistem Rehberi (DOCS)

1. OpenAI (ChatGPT) API Key Nasıl Alınır?

1. platform.openai.com adresine git ve kayıt ol.
2. Sağ üst profilden "API keys" sekmesine tıkla.
3. "+ Create new secret key" butonuna basarak anahtarını kopyala.

2. Gemini API Key Nasıl Alınır?

1. aistudio.google.com adresine git.
2. Google hesabınla giriş yap ve "Get API Key" butonuna basarak ücretsiz anahtarını oluştur.

3. Claude (Anthropic) API Key Nasıl Alınır?

1. console.anthropic.com adresine git.
2. Konsol panelinden "API Keys" bölümüne girip anahtarını üret.

4. Groq API Key Nasıl Alınır?

1. console.groq.com adresine git.
2. Panelden "API Keys" sekmesine girip anahtarını oluştur.

5. Grok (xAI / OpenRouter) API Key Nasıl Alınır?

1. openrouter.ai adresine kaydol.
2. Hesap ayarlarından "Keys" kısmına gidip yeni bir anahtar oluştur.
